# Novel · 沉浸式文字剧情引擎

手机、平板、电脑都能打开的中文互动剧情 Web App。写完人设与剧情指令后，导演引擎会一轮轮推进故事，每轮结尾给出三个走向，也可以自己输入；不满意随时回退到前几轮重开一条线。

> 界面与交互参考 nuvva.ai 的移动端对话形态：顶部是分幕信息 + 实时情感条，中间是正文，底部是一排可点开的实时反馈面板。

> **在线版**：<https://eventilldawn-dot.github.io/novel/>
>
> 项目是纯前端，可以直接发布到 GitHub Pages / Netlify / Cloudflare Pages，见 [DEPLOY.md](./DEPLOY.md)。线上版用浏览器直连模型（DeepSeek 支持跨域），Key 只存在访问者自己的浏览器里，不会上传到任何服务器。

## 一、快速开始

需要 Node.js 18 以上（本机已装 v24）。

**Windows**：双击目录里的 `start.bat`。

**命令行**：

```bash
cd outputs/novel
node server.js
```

启动后终端会打印两个地址：

```
本机访问   http://localhost:8787
局域网访问 http://192.168.x.x:8787   ← 手机 / 平板用这个
```

手机、平板与电脑连同一个 WiFi，直接在浏览器里打开局域网地址即可（可以「添加到主屏幕」，用起来和 App 一样）。端口被占用时：`PORT=8790 node server.js`。

## 二、接入模型

**默认就是 DeepSeek**（地址 `https://api.deepseek.com/v1`、模型 `deepseek-chat`），填上 Key 就能用。

> ⚠️ 最常见的坑：**Key 是 DeepSeek 的，地址却留在了 OpenAI**，这会直接 401。设置里点一下「DeepSeek（默认）」按钮就能把地址和模型一起切回来。

不配任何东西也能用：默认走**本地示例引擎**，全部交互都能跑通，但文字是模板生成的（这就是"上下文生硬"的原因）。想要真正的剧情质量，接一个模型（任何 OpenAI 兼容接口都行）：

**方式 A：页面里填**
点右上角 `⚙` → 选服务商（默认 DeepSeek）→ 填 Key → **先点「测试连接」**（会显示成功耗时或具体失败原因）→ 保存。

设置面板里有三个关键开关：

- **服务商**：DeepSeek / OpenAI / Kimi / 智谱 / 本地 Ollama 一键切换地址与模型名。
- **调用方式**：`自动`（本机服务优先，否则浏览器直连）/ `只用本机服务` / `只用浏览器直连`。放在网上给别人用时选自动或直连即可。
- **最大输出 tokens**：默认 8000。如果看到「模型输出被截断」，把它调大。

**方式 B：改文件**
复制 `config.example.json` 为 `config.json` 再填：

```json
{
    "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "sk-...",
    "model": "deepseek-chat",
    "temperature": 1.1,
    "maxTokens": 8000,
  "stream": true,
  "jsonMode": true
}
```

**方式 C：环境变量** `NOVEL_API_BASE` / `NOVEL_API_KEY` / `NOVEL_MODEL`（优先级低于 config.json）。

常见服务商的 `baseUrl`：

| 服务 | baseUrl |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| 月之暗面 | `https://api.moonshot.cn/v1` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` |
| 本地 Ollama | `http://localhost:11434/v1` |
| 中转 / 自建 | 填到 `/v1` 为止即可，程序会自动补 `/chat/completions` |

> 如果模型不支持 `response_format: json_object`，把设置里的「强制 JSON」关掉；程序在报错时会自动降级重试（去掉 JSON 模式 → 去掉额外参数），三轮都失败才退回本地引擎。

## 三、功能对照

**1. 人设剧情指令 → 开演**
设定页可以填：剧情名称、题材模板、人设剧情指令（世界观 / 主线 / 规则 / 节奏）、我扮演的角色、对方角色、开场状态、叙事风格 / 视角 / 篇幅、内容尺度。点「开始剧情」立刻生成第一幕。

**界面会自己长出来**：点「✨ 让导演按剧情自动配置按钮与情感条」，或者直接开始（默认开启自动配置），导演会读你的剧情设定，自己拟一套顶部按钮、底部面板和情感指标。比如写一个 1937 年上海租界的谍战剧情，它会给出：

- 顶部：`人设卡` `分幕地图` `情报线索`
- 底部：`酒桌眉眼` `暗语进度` `思路` `爵士乐单` `险情提示`
- 情感：`信任` `警觉` `试探欲` `愧疚` `压迫感`

没有 Key 的时候这一步会退化成**关键词匹配**（按剧情里的字眼挑最接近的题材模板），一样能用。

**2. 每轮三个走向 + 自由输入**
每轮正文结束处给出 A / B / C 三个方向明显不同的选项；下方始终保留输入框，不满意的走向可以直接手写（`Enter` 发送，`Shift+Enter` 换行）。玩家自己输入的内容会被严格承接，不会跳戏。

**3. 回到前几轮**
底部悬浮的 `‹ 3 / 12 ›` 是回合导航：左右切换，点中间的数字打开**时间轴**，可以跳到任意一轮。从中间某轮继续对话时，原来的后续剧情会自动存成**分支**（时间轴里能看到 `⑂1 从第 N 轮分出的另一条线`），不会被直接丢掉。还有「↻ 换一批走向」「↩ 回退一轮」两个快捷按钮。

**4. 顶部情感条 + 底部实时反馈面板**
- 顶部：分幕名 + 剧内时间 / 时段，下面是情感实时值（默认 好感度 / 愉悦度 / 羞耻度 / 痛苦 / 沉溺，可自定义），带 ↑↓— 趋势箭头和彩色进度条，每轮变化时会闪一下。
- 底部：一排可点开的抽屉面板，点一下展开、再点收起。**面板是按剧情设定走的**，题材模板不同，按钮就不同：

  | 模板 | 底部按钮 |
  | --- | --- |
  | 直播拍摄 · 生活条件 | 心理活动 / 影片弹幕 / 已采精名单 / 自定义思路 / 生活条件 |
  | 现代都市 · 情感拉扯 | 心理活动 / 情绪波动 / 关系网 / 自定义思路 / 生活条件 |
  | 古风宫廷 · 权谋 | 心理活动 / 风闻流言 / 关系网 / 自定义思路 / 家底账目 |
  | 悬疑推理 | 心理活动 / 线索板 / 嫌疑人名单 / 自定义思路 / 生活条件 |
  | 末世求生 | 心理活动 / 电台杂音 / 队伍成员 / 自定义思路 / 物资储备 |
  | 奇幻冒险 | 心理活动 / 酒馆传言 / 队伍成员 / 自定义思路 / 行囊与金币 |

  顶部按钮（人设卡 / 分幕地图 / 剧情线索 …）同理，也随设定变化。**两类按钮都能在设定页自由增删改名**，每个面板还能选数据形态：文字 / 列表 / 卡片 / 思路。

**5. 自定义思路面板**
「思路」型面板除了显示导演给的幕后笔记，底部还有一个输入框：写完点「注入」，内容会直接填进对话输入框，可以接着改再发送。

**6. 引擎状态随时可见**
接上模型前，正文区顶部会有一条常驻提示，说明现在是本地示例引擎（文字会偏生硬）；某一轮模型调用失败时，这条提示会变成红色并带上具体原因（比如 `401 Key 无效` / `输出被截断`），点「去设置」直接跳设置。每一轮左下角也会标注这一轮是谁生成的。

## 四、面板系统（关键概念）

每一条「按钮」= 一个 Panel，定义长这样：

```js
{
  id: 'living',          // 唯一 key，模型返回内容时按这个对齐
  label: '生活条件',      // 按钮上显示的字
  kind: 'kv',            // text 文字 | list 列表 | kv 卡片 | notes 带注入输入框
  hint: '用键值卡片描述主角的现实处境：当前场所 / 日常居所 / 本次收益预估 / 最想改善的一项'
}
```

`hint` 会原样写进给模型的提示词，所以**改 hint 就能改内容形态**。比如把「生活条件」的 hint 改成「列出房租、欠款、本月收入与下个月的目标」，生成出来的就是账单风格。

内置面板库在 `public/js/presets.js` 的 `PANEL_LIBRARY`，可以直接加新条目；题材模板 `TEMPLATES` 也在同一个文件里，照着加一个就能出现在设定页。

## 五、跨设备同步（数据存在哪）

### 有两种模式

**① 连着电脑上的服务（推荐，自动同步）**

剧情存在跑 `server.js` 的那台电脑上：

```
novel/data/sessions.json      ← 唯一主库，所有设备共用这一份
novel/data/sessions.json.bak  ← 上一次的自动备份
```

启动时终端会打印局域网地址，例如：

```
局域网访问 http://192.168.3.37:8787   (WLAN · 手机/平板用这个)
剧情存储   data\sessions.json  (各端共用一份)
同步口令   ed673e0e403e73676b0c038b
```

手机、平板、电脑只要打开**同一个地址**，看到的就是同一份剧情：在手机上选了一个走向，电脑上刷新就在。侧栏顶部会显示 `● 已同步 · 存在本机服务 · N 部剧情`，点它可以打开同步设置。

> 建议把局域网地址「添加到主屏幕」，用起来和 App 一样。局域网 IP 偶尔会变，以终端每次打印的为准。

**② 没有服务时（例如直接开线上版）**

只能存在**当前这台设备的浏览器** `localStorage` 里，换设备看不到。侧栏会显示 `▣ 仅本机浏览器` 提醒你。

想让线上版也同步，有两种办法：

- 在线上版的设置里填**服务地址 + 同步口令**，让它连回你电脑上的服务（需要那个地址是 https，否则浏览器会以"混合内容"为由拦截；用 Cloudflare Tunnel 之类的内网穿透即可）。
- 或者干脆所有设备都只用局域网地址，最简单。

### ③ 出门在外也能用（公网隧道）

双击 `tunnel.bat`，它会自动：启动本机服务 → 建一条 Cloudflare 免费隧道 → 打印一个公网地址：

```
公网地址（手机/平板用这个，加到主屏幕即可）：

    https://apache-proudly-ricky-laughing.trycloudflare.com/?token=ed673e0e403e73676b0c038b
```

把这个地址（**要带 `?token=`**）在手机上打开，就相当于直接连回了你电脑上的服务 —— 不需要注册、不需要域名、不需要配任何东西，在外面用流量也能写，写完整条记录都在你电脑那一份主库上。

注意：

- 免费隧道的地址**每次重启都会变**，以窗口里打印的为准。
- 带 `?token=` 的链接等于钥匙，别发出去。不带口令访问一律 403。
- 想用线上版 `eventilldawn-dot.github.io/novel` 连回来也可以：在它的设置里填「本机服务地址 + 同步口令」即可（两端都是 https，不会被混合内容拦截）。但地址一变就要重填一次，不如直接用隧道地址省事。
- 如果刚更新过代码，GitHub Pages 的静态文件会缓存 10 分钟，页面表现不对就强刷一次（Ctrl+Shift+R）。

### ④ 电脑关机时也能写（离线 PWA）

app 内置了 Service Worker，只要从 **https 地址**打开过一次，就会被缓存下来，**电脑关机也能打开**：

1. 手机用 https 地址打开 app（线上版，或隧道地址）；
2. 浏览器菜单里选「添加到主屏幕 / 安装应用」；
3. 之后电脑关着也能点开它写剧情 —— 此时侧栏显示 `▣ 仅本机浏览器`，数据存在手机上；
4. 等电脑开机、手机再打开同一个地址，就会自动**合并**：手机离线写的内容推到电脑，电脑上写的也拉回手机。

> 为什么必须 https：浏览器规定只有 https / localhost 才允许离线缓存。`http://192.168.x.x` 这种局域网地址做不到。

### 三种方案怎么选（都不用花钱）

| 方案 | 电脑能关吗 | 要注册吗 | 数据存在哪 |
| --- | --- | --- | --- |
| 局域网地址 | ❌ 必须开着 | 不用 | 你的电脑 |
| 临时隧道 `tunnel.bat` | ❌ 必须开着 | 不用 | 你的电脑 |
| **Tailscale Funnel** | ✅ 手机离线写，开机自动汇合 | 免费注册一个 Tailscale 账号（不用信用卡） | 你的电脑，地址固定不变 |
| 复制 / 粘贴 搬数据 | ✅ | 不用 | 手动搬，适合偶尔用 |

### ⑤ 已经配好的 Tailscale 方案

这台电脑已经装好 Tailscale 并开启了 Funnel，公网地址是**永久固定**的：

```
https://laptop-am1foeoo.tailaf5498.ts.net/?token=ed673e0e403e73676b0c038b
```

它直接代理到本机的 `127.0.0.1:8787`，所以 app 和接口是**同一个源**，不需要配跨域、也不会被混合内容拦。

手机上这么做：

1. 打开上面这个带 `?token=` 的地址；
2. 浏览器菜单 →「添加到主屏幕 / 安装应用」；
3. 以后电脑关着也能点开写（离线 PWA），电脑开机后自动汇合。

> 更稳的做法是**手机上也装一个 Tailscale**（免费 App，用同一个账号登录）：
> 这样域名会走 Tailscale 的加密内网直达这台电脑，不走公网，不受运营商影响。

管理命令：

```bash
tailscale funnel status     # 看当前公网映射
tailscale funnel --https=443 off   # 关掉公网访问
tailscale up / down         # 连接 / 断开
```

> 注意：Tailscale 的 Funnel 每次电脑开机后会自动恢复（配置存在服务里），
> 但 **Novel 自己的服务要手动启动**（双击 `start.bat`），或者做成开机自启。

急着用又不想注册的话，`⇅ 数据` 里有 **「复制全部到剪贴板」/「从剪贴板导入」**：
手机上复制，用微信发给自己，电脑上粘贴导入，一样能把剧情搬过来。

### 同步是怎么做的

- 启动时拉取服务器的全量数据，与本机数据**按 `id` + `updatedAt` 合并**（同 id 保留更新的那份），合并结果再写回服务器。
- 之后每次生成新回合、回退分支、删除剧情，都会在 0.8 秒内增量推送。
- 服务器写入是原子的（先写 `.tmp` 再改名），并保留 `.bak` 备份。
- 同步口令用于拦截跨域访问：同源访问不需要，从别的网站连过来必须带上。

### 备份

侧栏 `⇅ 数据` 可以**导出 JSON 备份**、导入、清空。直接把 `data/sessions.json` 拷走也是完整备份。

## 七、常见问题

**生成很慢 / 一直转圈**：模型越强越慢，可以在设置里把「流式输出」打开（默认开），文字会边生成边出现。

**报「已降级为本地示例引擎」**：说明模型调用失败，提示条会带上原因（Key 无效、地址错、余额不足、返回不是 JSON 等）。修好设置后点「↻ 换一批走向」重试。

**每轮太长 / 太短**：设定页的「单轮篇幅」控制；想让某几轮更长，直接在输入框里写「这一轮写长一点」。

**想换情感指标**：设定页「情感指标」手填，逗号分隔，最多 6 个；下面有 7 套预设一键切换（好感型 / 拍摄现场型 / 宫廷权谋型 / 悬疑推理型 …）。

**手机上打不开局域网地址**：确认在同一 WiFi；Windows 防火墙第一次会弹窗，选「允许」；公司/校园网可能隔离了设备互访。
